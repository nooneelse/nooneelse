- 🏗️ I design and build backends with **PHP 8+ and Symfony 7/8**, following **DDD and SOLID** principles. The "S" stands for "Seriously, one responsibility."
- 🛒 Long-time e-commerce developer on **Magento 1 & 2**, with **Sylius**, **Akeneo PIM**, and **Sulu CMS**. I have waited for more reindexes than buses.
- 🔌 I build **REST APIs** with **API Platform** and **OpenAPI**, and I return the right HTTP status code even when nobody is watching.
- 🐳 Author of [**docker-compose-updater**](https://github.com/nooneelse/docker-compose-updater), because "it works on my machine" is not a deployment strategy.
- 🌐 More about me and my work at [**bouzoumita.dev**](https://bouzoumita.dev).
- 💬 Ask me about **PHP, Symfony, Magento, API design & backend architecture**. Do not ask me why `strpos()` and `array_search()` disagree on argument order. Nobody knows.

### 🐘 Things you should know

- PHP has been declared dead every single year of my career. We are both still shipping to production.
- I have said "it's probably the cache" more often than "good morning". I was right most of the time.
- Username checks out: when the build breaks on a Friday at 18:00, **nooneelse** fixes it.
- I know what `T_PAAMAYIM_NEKUDOTAYIM` means. I am not sure this is something to be proud of.
- There are two hard problems in computer science: cache invalidation, naming things, and off-by-one errors.
